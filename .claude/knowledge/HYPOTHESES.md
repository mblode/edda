# Interview hypotheses — Blode.md

Falsifiable guesses, written before the next five signups are asked anything. Mapped to `.claude/knowledge/GOALS.md`. If an interview does not move one of these, the question was chitchat.

**H1.** The person who signs up already writes Markdown or MDX in a git repo and reviews docs in a pull request. [G1]

**H2.** Her current public docs are on Mintlify, Docusaurus, VitePress, GitBook, or Notion — not on Blode.md and not “nothing.” [G2]

**H3.** She looked this week because docs lagged a release, an agent cited a stale page, or she would not stand up a Docusaurus app for a launch. [G3]

**H4.** She has never paid a docs host more than $0, or she just refused a seat/credit invoice, and she will not pay Blode.md either. [G4]

**H5.** She would pick a host that has no visual editor over an otherwise equal host that has one. [G5]

**H6.** She already says “the pull request is the review” or “docs as code”; she does not say “knowledge layer.” [G6]
